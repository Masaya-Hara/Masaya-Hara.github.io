# Project specification

- This is Masaya Hara's academic mathematics website.
- The site will ultimately be published at https://masaya-hara.github.io/.
- The GitHub repository will be `masaya-hara/masaya-hara.github.io`.
- The academic homepage and the interactive mathematical surface gallery will be part of one website.
- The surface gallery will eventually live under `/surfaces/`.
- Technical stack: Astro, TypeScript, Three.js, npm.
- The site should be static-first.
- Detailed information architecture, visual design, page content, and surface viewer architecture are not yet decided.
